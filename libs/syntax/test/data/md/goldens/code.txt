󰲡 Code fences

Plain (no language):

╭─ code ───────────────────────────────────────────────────────────────────────╮
│ 1 plain preformatted text                                                    │
│ 2     indented line                                                          │
╰──────────────────────────────────────────────────────────────────────────────╯

With a language:

╭─  ──────────────────────────────────────────────────────────────────────────╮
│ 1 import std.stdio;                                                          │
│ 2                                                                            │
│ 3 void main()                                                                │
│ 4 {                                                                          │
│ 5     writeln("hello");                                                      │
│ 6 }                                                                          │
╰──────────────────────────────────────────────────────────────────────────────╯

With a label:

╭─  [example.d] ──────────────────────────────────────────────────────────────╮
│ 1 enum answer = 42;                                                          │
╰──────────────────────────────────────────────────────────────────────────────╯

Short and long lines:

│ 1 x=1                                                                        │
│ 2 printf '%s\n' "a deliberately long command line that exceeds typical width │
