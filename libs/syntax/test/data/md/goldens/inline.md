# Inline styles

Plain text with *emphasis*, **strong**, ***both***, ~~strikethrough~~, and
`inline code`.

Nested: **bold with *italic inside* and `code` too**.

A [link](https://example.com), a [link with **bold** text](https://example.com),
and an autolink <https://example.com>.

An image: ![alt text](image.png) inline with prose.

A hard break at the end of this line\
continues here.

Escapes: \*not emphasis\*, \`not code\`, a literal backslash \\.

Unicode: emoji 🎉, CJK 漢字テスト, combining é, box glyphs ─│┼╭╮.

Long-word wrapping: antidisestablishmentarianism-supercalifragilisticexpialidocious
inside a sentence that should wrap at narrow widths.
