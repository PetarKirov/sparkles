# Lists

Unordered:

- first item
- second item with a longer text that should wrap under the text, not under
  the bullet, when the width is narrow
- third item

Ordered:

1. first
2. second
3. third

Nested unordered (four depths):

- depth one
  - depth two
    - depth three
      - depth four
  - back to depth two
- depth one again

Nested ordered inside unordered:

- outer bullet
  1. inner ordinal one
  2. inner ordinal two
     1. third depth ordinal
- another outer bullet

Ordered with nested unordered:

1. outer one
   - inner bullet
   - another inner bullet
2. outer two

Task list:

- [ ] unchecked task
- [x] checked task
- [ ] task with nested list
  - [x] nested checked
  - [ ] nested unchecked

Item with multiple paragraphs:

- first paragraph of the item

  second paragraph of the same item

- next item
