# Testing — oracles and evidence

## Abstract

This page lists the oracles that check the `sparkles:ui` design system's
requirements and the evidence gathered against them. Each oracle states why it
is independent of the code it checks, and each evidence row names the revision,
command, configuration and remaining gap.

## Introduction

The trace runs from a requirement to a falsifying scenario, to an oracle, to
scoped evidence. An oracle must be independent of the implementation: a round
trip alone is not one. The requirements live in [SPEC.md](./SPEC.md) and its
sibling pages, and delivery order lives in [PLAN.md](./PLAN.md). An evidence row
is a record of what one revision showed; where a later decision changes a
contract, the row stays and a note below the ledger names the change.

**O1 notes.** `ui-gallery` takes the role Storybook has for web design
systems: the canonical rendering of a component is the one the reference
application produces (D17).

## Omitted combinations

`O1` renders three capability profiles, not the 2^n flag combinations; the
projection functions (`O7`) are exhaustive instead, so a flag combination
outside the profiles is covered at the function level, not the page level. `O5`
covers the emulators its corpus recorded
([emulator presets](./capabilities.md#emulator-presets)); others are
`unverified` until a transcript is captured.

**Note on `feat/tui-grapheme-clusters`.** The gap that revision recorded — a
cluster longer than a TUI cell's 16 inline bytes folds on every target — is not
the contract. [`GLY12`](./glyphs.md#typography-and-sizing) keeps such a cluster
whole through the cell's overflow storage (base/text `TXT-CELL8`) and fails explicitly when that
storage is exhausted (D50). The row stays evidence for `GLY6`'s fold on a
terminal that does not cluster; `GLY12` has no evidence.

**Note on wrapping evidence.** Evidence for the toolkit's wrapping and cutting
(`LAY5`, `LAY10` and `LAY14` in the [layout specification](../ui/layout.md))
stands for the delivered code and is pending base's cutover of those callers
(D51).
