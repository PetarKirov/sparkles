# Keyboard vocabulary (`KBD`)

_**Status:** proposed · **Date:** 2026-09-21 · **Owner:** `sparkles:ui`
(`keymap.d`), as one overlay table · **Scope:** the **minimal** set of
bindings every Sparkles application shares, so a user who learned one learns
all. Everything else stays application policy under [`KEY`](../ui/keymap.md)._

The machinery is [`KEY1`–`KEY12`](../ui/keymap.md); this page adds a check, not
a mechanism. `sparkles.ui.keymap_universal` holds the universal keys and the
reserved chords as data. An application marks each command that implements a
universal meaning with `@means`, and its tests assert that no row rebinds a
fixed key (`firstRebound`) and none binds a reserved one (`firstReserved`).
hue, ui-gallery and diagram all carry that test.

| ID     | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Status      | Traces to                                                                                                                        |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `KBD1` | The **fixed rows** exist in every Sparkles application and mean the same thing in every context: `q` / `Esc` (and Android's Back) close the innermost thing (overlay → pane → app, in that order); `?` opens the key guide (lantern); `Tab` / `Shift-Tab` move focus; `/` starts a search where one exists. An application may leave one unbound where it has no meaning, never rebind it. The **focus rows** belong to the focused control: `Enter` activates it and `Space` toggles it, where it has those actions. With no such control focused, the application may bind them (hue's leader is `Space`; diagram pans with it) — D47. | full        | `keymap_universal` `firstRebound`; `keymap.universalRowsAndReservedKeys` in hue, ui-gallery and diagram                          |
| `KBD2` | **Motion** rows: `h j k l` and the arrow keys are synonyms; `g g` / `G` go to start/end; `Ctrl-D` / `Ctrl-U` half-page; `Page Up/Down` whole page. A component that scrolls or moves a cursor honours all of them (`KEY9`: unnamed modifiers are ignored).                                                                                                                                                                                                                                                                                                                                                                               | partial     | hue `NAV`; `ScrollView`                                                                                                          |
| `KBD3` | **Reserved keys are never bound** by a Sparkles application: `Ctrl-C` (interrupt), `Ctrl-Z`, `Ctrl-S`/`Ctrl-Q` (flow control), `Ctrl-\`. The TUI host quits on `Ctrl-C` itself, unless a component holds the keyboard grab — an embedded shell, which must receive it (D48). A table containing a reserved key fails the conformance test.                                                                                                                                                                                                                                                                                               | full        | `keymap_universal` `firstReserved`; `ui_app.tui_loop.ctrlCInterruptsUnlessGrabbed`; ui-gallery's Terminal page grabs             |
| `KBD4` | **Footer hints** render bindings as `key description` pairs joined by `·`, keys in the guide's normalised spelling, in resolution order, and change with focus (`bindingsAt`). The format is the lantern's, so the footer and the guide never disagree.                                                                                                                                                                                                                                                                                                                                                                                  | partial     | `lantern.d`; hue status bar                                                                                                      |
| `KBD5` | **Text inputs** honour the Readline subset: `Ctrl-A`/`Ctrl-E` (line ends), `Ctrl-U`/`Ctrl-K` (kill to start/end), `Ctrl-W` (kill word), `Alt-B`/`Alt-F` (word motion). `Ctrl-I` and `Ctrl-M` are `Tab` and `Enter` unless `keyRelease` (kitty keyboard) disambiguates them.                                                                                                                                                                                                                                                                                                                                                              | not started | `WGT14`; proposed `EDT`                                                                                                          |
| `KBD6` | A Sparkles application ships its **effective table** — universal rows, overlay, and its own — through `--list-keys`, so the guide, the docs and the binary agree by construction.                                                                                                                                                                                                                                                                                                                                                                                                                                                        | full        | `keymap_universal` `writeKeyTable`; `--list-keys` in hue (overlay included), ui-gallery and diagram; `keymap.listingHasEveryRow` |
