# Sessions: the exit prompt, tabs, splits and restore (`TSS`)

_**Status:** proposed · **Date:** 2026-10-02 · **Owners:**
`sparkles:terminal-view` (respawning a pane; the pane pool); `apps/terminal`
(the workspace: tabs, splits, the prompt, restore); `sparkles:ui` (the dock
layout, [`DCK`](../ui/containers.md)) · **Scope:** what happens when a
program ends, and how many programs one window holds._

## Why

The app is one pane. When its program exits, the app quits (status 0) or
holds a banner it cannot leave (`ExitBehavior.holdOnFailure`). zellij shows a
better answer — the pane stays, says how the program ended, and offers to run
it again or drop to a shell — and every desktop terminal has tabs and splits.
The parts exist: `TerminalView` runs as many instances as a host pumps
(ui-gallery's `TerminalStore`), and `DockLayout` is a tested split-and-tab
tree with a serialized form.

## The exit prompt (`TSS1`–`TSS5`)

| ID     | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Status      | Traces to                           |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ----------------------------------- |
| `TSS1` | `behaviour.onExit` decides what a pane does when its program exits: `promptOnFailure` (default) closes it on status 0 and shows the prompt otherwise; `prompt` always shows it; `close` always closes; `hold` keeps the screen with a status line and no actions. A pane whose program was given explicitly (`terminal -- cmd`, a "run command" pane) always shows the prompt, as in zellij. A signal death counts as a failure.                                                                                                                                                                                                                                                                                                        | not started | `ExitBehavior`                      |
| `TSS2` | The prompt is a banner across the bottom of the pane (mockup E1): it keeps the program's last screen and scrollback above it, shows the exit status (or the signal) with a status mark that is not colour alone ([`ACC3`](../design-system/SPEC.md)) and the command, truncated to one line; **activating the status line expands it** to the full command, its working directory and its start and end times, scrolling when longer than the space, and collapses again on a second activation. Three actions follow: **Enter** re-runs the same command with the same arguments, environment and directory; **Esc** starts the user's shell in the pane's last directory; **Ctrl+C** closes the pane. On touch the three are buttons. | not started | [design](./design.md)               |
| `TSS3` | Re-run and shell replace the pane's process in place (`TerminalView.respawn`): the pane keeps its id, title pin, position and scrollback (a separator line marks the boundary); the VT state is reset. A respawn that fails to start keeps the prompt and shows the error.                                                                                                                                                                                                                                                                                                                                                                                                                                                              | not started | `TerminalView.spawnChild`           |
| `TSS4` | "The user's shell" is `$SHELL` (then the passwd entry, then `/bin/sh`) on the desktop; on Android it is the session's own command — nix-on-droid's `login` in bootstrap mode, `/system/bin/sh` in plain mode ([NOD4/NOD7](./android.md#requirements)). The installer-to-login handoff ([D4](./android.md#decisions)) becomes a respawn of the same pane.                                                                                                                                                                                                                                                                                                                                                                                | not started | `DroidTerminal`, `configureSession` |
| `TSS5` | Closing the last pane quits the app, as today. On Android that also ends the process (`exit(0)` after `runApp` returns).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | not started | `androidMain`                       |

## Tabs and splits (`TSS6`–`TSS15`)

| ID      | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Status      | Traces to                     |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ----------------------------- |
| `TSS6`  | The workspace is an ordered list of tabs, each a `DockLayout` of panes ([`DCK1`](../ui/containers.md)); a pane is a `TerminalView` owned by a pool whose slots are heap-pinned (a view cannot move: its VT callbacks hold its address). Limits: 32 tabs, 16 panes per tab; a command that would exceed one is refused with a toast.                                                                                                                         | not started | `TerminalStore`, `DockLayout` |
| `TSS7`  | Every live pane is pumped every frame, visible or not, so a background tab's program keeps running and its output keeps draining ([NOD9](./android.md#requirements)'s rule, per pane).                                                                                                                                                                                                                                                                      | not started | `TerminalView.pump`           |
| `TSS8`  | Commands: new tab, close tab, next/previous tab, go to tab N, rename tab, split right, split down, focus left/right/up/down, close pane, zoom pane (toggle filling the tab), resize the focused split. New panes start in the focused pane's directory ([`TPR4`](./protocols.md)).                                                                                                                                                                          | not started | [`TKM`](./keymap.md)          |
| `TSS9`  | Input routing is the container's ([`DCK13`](../ui/containers.md)): keys go to the focused pane; a pointer event goes to the pane under it, translated to pane-local coordinates — today the component reads absolute window coordinates, which an embedded pane must not. A tap or click on a pane focuses it.                                                                                                                                              | not started | `paintPanePx`                 |
| `TSS10` | Divider drags resize the split (`DCK3`); each pane is resized in whole cells and its program notified once per settled size, not once per frame of the drag.                                                                                                                                                                                                                                                                                                | not started | `DCK3`                        |
| `TSS11` | The focused pane is visible without colour ([`ACC4`](../design-system/SPEC.md)): its header title is bold or its border heavier, in addition to `Slot.chromeFocused`.                                                                                                                                                                                                                                                                                       | open        | [design](./design.md)         |
| `TSS12` | A tab strip shows each tab's icon and title ([`TPR1`](./protocols.md)), an unseen-notification or activity mark, and a new-tab affordance; it is hidden while there is one tab unless `tabs.showStrip = always`; overflow scrolls with the active tab kept visible (hue's [`TAB4`](../hue/tab-view.md)).                                                                                                                                                    | open        | [design](./design.md)         |
| `TSS13` | **Touch:** a tap on a tab selects it; a long-press opens a menu (rename, close, notification setting for the tab); a two-finger horizontal swipe over the terminal moves to the next or previous tab (a one-finger drag still scrolls); dividers drag; splits come from the guide or the MENU key ([`TKM7`](./keymap.md)). In portrait, a zoomed pane is the default way to read one of several splits.                                                     | open        | [D25](./decisions.md)         |
| `TSS14` | **Restore** (`behaviour.restore`, on by default): the workspace — tabs, their layouts, each pane's title pin, icon, directory and command — is saved on every structural change and on going to the background, and re-created on the next start with fresh shells in those directories; a pane that ran an explicit command comes back at its exit prompt (`TSS2`) rather than running it. A layout that fails to load is discarded with a logged warning. | not started | `DCK2`                        |
| `TSS15` | **Focus from outside:** an operation naming a pane (a notification's deep link, [`TPR12`](./protocols.md); an entry in the notification log, [`TPG10`](./pages.md)) selects its tab, un-zooms another zoomed pane if needed, and focuses it.                                                                                                                                                                                                                | not started | [D15](./decisions.md)         |
