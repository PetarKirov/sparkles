# Sessions: the exit prompt, tabs, splits and restore (`TSS`)

_**Status:** proposed · **Date:** 2026-10-02 · **Owners:**
`sparkles:terminal-view` (respawning a pane; the pane pool); `apps/terminal`
(the workspace: tabs, splits, the prompt, restore); `sparkles:ui` (the dock
layout, [`DCK`](../ui/containers.md)) · **Scope:** what happens when a
program ends, and how many programs one window holds._

## Why

The app is one pane. When its program exits, the app quits (status 0) or
holds a banner it cannot leave (`ExitBehavior.holdOnFailure`). zellij shows a
better answer — the pane stays, says how the program ended, and offers to run
it again or drop to a shell — and every desktop terminal has tabs and splits.
The parts exist: `TerminalView` runs as many instances as a host pumps
(ui-gallery's `TerminalStore`), and `DockLayout` is a tested split-and-tab
tree with a serialized form.

## The exit prompt (`TSS1`–`TSS5`)

| `TSS1` | `behaviour.onExit` decides what a pane does when its program exits: `promptOnFailure` (default) closes it on status 0 and shows the prompt otherwise; `prompt` always shows it; `close` always closes; `hold` keeps the screen with a status line and no actions. A pane whose program was given explicitly (`terminal -- cmd`, a "run command" pane) always shows the prompt, as in zellij. A signal death counts as a failure.                                                                                                                                                                                                                                                                                                        | full                                                                                                            | `exitActionFor`, `WorkspaceHost.applyExits`                                                                   |
| `TSS2` | The prompt is a banner across the bottom of the pane (mockup E1): it keeps the program's last screen and scrollback above it, shows the exit status (or the signal) with a status mark that is not colour alone ([`ACC3`](../design-system/SPEC.md)) and the command, truncated to one line; **activating the status line expands it** to the full command, its working directory and its start and end times, scrolling when longer than the space, and collapses again on a second activation. Three actions follow: **Enter** re-runs the same command with the same arguments, environment and directory; **Esc** starts the user's shell in the pane's last directory; **Ctrl+C** closes the pane. On touch the three are buttons. | partial: a long command wraps and scrolls under the wheel; the touch drag is wired but not yet seen on a device | `exitBanner`, `commandLines`, `WorkspaceHost.scrollBanner`, `WorkspaceHost.tap`, `CoreState.embedderOwnsExit` |
| `TSS3` | Re-run and shell replace the pane's process in place (`TerminalView.respawn`): the pane keeps its id, title pin, position and scrollback (a separator line marks the boundary); the VT state is reset. A respawn that fails to start keeps the prompt and shows the error.                                                                                                                                                                                                                                                                                                                                                                                                                                                              | full                                                                                                            | `TerminalView.respawn`, `respawnRunsTheProgramAgainInPlace`                                                   |
| `TSS4` | "The user's shell" is `$SHELL` (then the passwd entry, then `/bin/sh`) on the desktop; on Android it is the session's own command — nix-on-droid's `login` in bootstrap mode, `/system/bin/sh` in plain mode ([NOD4/NOD7](./android.md#requirements)). The installer-to-login handoff ([D4](./android.md#decisions)) becomes a respawn of the same pane.                                                                                                                                                                                                                                                                                                                                                                                | partial: the installer hands over to the login by respawning the pane, not yet seen on the phone                | `DroidTerminal.view`, `configureSession`                                                                      |
| `TSS5` | Closing the last pane quits the app, as today. On Android that also ends the process (`exit(0)` after `runApp` returns).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | full                                                                                                            | `Workspace.empty`, `DesktopTerminal.view`                                                                     |

## Tabs and splits (`TSS6`–`TSS15`)

| ID      | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Status                                                                                                                                                                                                                                                            | Traces to                                                                                                   |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `TSS6`  | The workspace is an ordered list of tabs, each a `DockLayout` of panes ([`DCK1`](../ui/containers.md)); a pane is a `TerminalView` owned by a pool whose slots are heap-pinned (a view cannot move: its VT callbacks hold its address). Limits: 32 tabs, 16 panes per tab; a command that would exceed one is refused with a toast.                                                                                                                                                                                                                                                                                                                                                                                                                                                          | full                                                                                                                                                                                                                                                              | `Workspace`, `TerminalPool`, `maxTabs`, `maxPanesPerTab`                                                    |
| `TSS7`  | Every live pane is pumped every frame, visible or not, so a background tab's program keeps running and its output keeps draining ([NOD9](./android.md#requirements)'s rule, per pane).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | full                                                                                                                                                                                                                                                              | `WorkspaceHost.frame`                                                                                       |
| `TSS8`  | Commands: new tab, close tab, next/previous tab, go to tab N, rename tab, split right, split down, focus left/right/up/down, close pane, zoom pane (toggle filling the tab), resize the focused split. New panes start in the focused pane's directory ([`TPR4`](./protocols.md)).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | partial: renaming a tab needs a text field (M8)                                                                                                                                                                                                                   | `WorkspaceHost.run`, `Workspace.split`, `Workspace.focusToward`, `Workspace.resizeToward`                   |
| `TSS9`  | Input routing is the container's ([`DCK13`](../ui/containers.md)): keys go to the focused pane; a pointer event goes to the pane under it, translated to pane-local coordinates — today the component reads absolute window coordinates, which an embedded pane must not. A tap or click on a pane focuses it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | full                                                                                                                                                                                                                                                              | `handle_mouse` (pane origin), `WorkspaceHost.paneAt`, `DroidTerminal.onPointer`                             |
| `TSS10` | Divider drags resize the split (`DCK3`); each pane is resized in whole cells and its program notified once per settled size, not once per frame of the drag.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | full                                                                                                                                                                                                                                                              | `Workspace.resizeSplit`, `Workspace.moveDivider`, `WorkspaceHost.dragDivider`, `WorkspaceHost.touchDivider` |
| `TSS11` | The focused pane is visible without colour ([`ACC4`](../design-system/SPEC.md)) in every `ui.paneChrome` ([`TCF13`](./config.md)): `reveal` (default) draws no chrome, marks the focused pane with an accent corner and shows a pane's header — title, directory, split, zoom, close — while it is hovered (desktop) or after a tap on it (touch), until the next tap elsewhere; `header` draws a one-line header on every pane, bold on the focused one; `framed` draws a rounded frame with the title set in its border, heavier on the focused one (mockup E).                                                                                                                                                                                                                            | partial: reveal, header and framed all draw (desktop screenshots); a pane's toolbar shows at its top on hover and on a tap; the reveal toolbar's split always splits right                                                                                        | `paneBoxes`, `paneHeader`, `paneFrame`, `paneToolbar`, `WorkspaceHost.placeChrome`                          |
| `TSS12` | Tabs and their panes are one **tree** (mockup E): each tab with its icon ([`TPR1`](./protocols.md)), title, pane count and an unseen-notification mark, expandable to its panes — icon, title, directory, a failed exit shown as such — with the current tab and focused pane marked. A search field filters tabs and panes by title, program and directory, ranked by `sparkles:fuzzy`; matching tabs open to show their matches. Choosing an entry selects that tab and focuses that pane, and closes the tree where it was an overlay.                                                                                                                                                                                                                                                    | partial: the tree lists tabs and panes with icon, title, pane count, directory or exit and the unseen mark, filters and ranks with `sparkles:fuzzy`, opens matching tabs and picks with Enter or a tap; per-pane unseen counts wait for the notification log page | `TabTree`, `WorkspaceHost.treeTabs`                                                                         |
| `TSS13` | **Opening the tree** follows `ui.tabsOpener` ([`TCF12`](./config.md)): `pill` — a pill naming the current tab, its position and unseen count, whose tap opens the tree as a floating panel below it; `rail` — a narrow rail of tab icons, a new-tab button and a tree button, whose tap slides the full tree out beside the rail. The tree never opens on an edge swipe — the system Back gesture owns the screen edges — and tabs are not switched by swiping. Search sits at the bottom of the panel on touch (within reach of the keyboard) and at the top on the desktop. A tap outside, Back or `Esc` closes it. Splits come from the pane header's actions, the key guide and the MENU key; dividers drag; in portrait a zoomed pane is the default way to read one of several splits. | partial: the pill (centred on a phone, with the key hint on the desktop) and the rail open the tree in its panel, search at the bottom on touch and on top on the desktop; dividers do not drag yet (`TSS10`)                                                     | `pillBand`, `rail`, `usesPill`, `WorkspaceHost.toggleTree`                                                  |
| `TSS14` | **Restore** (`behaviour.restore`, on by default): the workspace — tabs, their layouts, each pane's title pin, icon, directory and command — is saved on every structural change and on going to the background, and re-created on the next start with fresh shells in those directories; a pane that ran an explicit command comes back at its exit prompt (`TSS2`) rather than running it. A layout that fails to load is discarded with a logged warning.                                                                                                                                                                                                                                                                                                                                  | partial: restore seen on the desktop and the phone (tabs, splits, fresh shells); on the phone each pane comes back in its directory only when the shell reports it with OSC 7, which Nix-on-Droid's bash does not, and proot hides a guest's `chdir` from `/proc` | `saved`, `restored`, `WorkspaceHost.restore`, `WorkspaceHost.refreshCwds`                                   |
| `TSS15` | **Focus from outside:** an operation naming a pane (a notification's deep link, [`TPR12`](./protocols.md); an entry in the notification log, [`TPG10`](./pages.md)) selects its tab, un-zooms another zoomed pane if needed, and focuses it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | full                                                                                                                                                                                                                                                              | `Workspace.focusPane`, `DesktopIntegration.tick`, `DroidPlatform.focusPane`, `NotificationPage.openEntry`   |
