# `sparkles:source-view`

Source and Markdown presentation over the shared widget tree. The library
turns syntax events and document structure into source-addressed spans that
work across recording, terminal and native hosts.

- [Highlighted editing](./reference/editing.md) explains composing syntax
  ink with editor selections, carets, protected spans and input preedit.
- The [syntax library](../syntax/index.md) owns highlight events and themes.
- The [shared editor contract](../../specs/ui/editor.md) owns editing behavior.
