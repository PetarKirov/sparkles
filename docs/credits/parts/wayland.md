### Wayland

| Field          | Value                                          |
| -------------- | ---------------------------------------------- |
| Version source | nixpkgs `wayland`                              |
| Licence        | `MIT`                                          |
| Home           | https://wayland.freedesktop.org                |
| Ships as       | `-lwayland-client` on Linux, on the native arm |

The client library of the Wayland display protocol. `sparkles:wsi` opens the
terminal's window on a Wayland compositor with it: surfaces, input, the
clipboard and frame pacing.
