### libxkbcommon

| Field          | Value                                                        |
| -------------- | ------------------------------------------------------------ |

| Licence        | `MIT`                                                        |
| Home           | https://xkbcommon.org                                        |

on Wayland and on X11 alike, for `sparkles:wsi`'s keyboard input.
