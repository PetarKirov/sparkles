### xcb-imdkit

| Field          | Value                                      |
| -------------- | ------------------------------------------ |
| Version source | nixpkgs `xcb-imdkit`                       |
| Licence        | `LGPL-2.1-only`                            |
| Home           | https://github.com/fcitx/xcb-imdkit        |
| Ships as       | `-lxcb-imdkit` on Linux, on the native arm |

The X Input Method protocol over XCB. On X11, `sparkles:wsi` talks to an
input method (fcitx, ibus) through it, so composed text — CJK, accented
letters — reaches the terminal as typed.
