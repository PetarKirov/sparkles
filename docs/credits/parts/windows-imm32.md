### Windows IMM32

| Field          | Value                                                                     |
| -------------- | ------------------------------------------------------------------------- |
| Version source | operating system `Windows`                                                |
| Licence        | `LicenseRef-Windows-System-Library`                                       |
| Home           | https://learn.microsoft.com/en-us/windows/win32/intl/input-method-manager |
| Ships as       | `-limm32` on Windows                                                      |

The Input Method Manager, a system library of Windows itself: `sparkles:wsi`
reads composed text from input methods through it. Nothing of it is
distributed with sparkles, so there is no licence text to carry.
