## Discrepancies & caveats

- **D-LP1 (rows 4, 5, 6) — OCR repairs inside quoted material.** `box96` is a 1996 scan and the
  extraction damages words _inside_ passages the doc quotes: `he attached` → `be attached`
  (row 4), `progmmrningl` → `(programming)` (row 6). The doc prints the repaired forms without
  `[sic]` or brackets. These are unambiguous scanning errors, not editorial changes to meaning,
  but the quotes are **not byte-identical to the extraction** and a future editor diffing them
  will see mismatches. Re-verify against the PDF, not the `.txt`.
- **D-LP2 (row 12) — a mechanism inferred across a page break.** "Boxes carry source positions;
  a comment is placed relative to the boxes whose original positions bracket it" continues past
  where the extraction truncates (`Boxes have …`). The reading is consistent with the quoted
  sentence in row 11 and with §5's stated approach, but the _mechanism_ has not been read. Read
  `box96` §5 in full before relying on this in [`concepts.md`](./concepts.md) or the proposal.
- **D-LP3 (row 20) — the formatter specialization is ours.** Both papers are about
  _refactoring_. Reading Correctness as `PARSE(FORMAT(s)) = PARSE(s)` and Preservation as the
  contract for untouched regions is this survey's adaptation. It is the intellectual bridge to
  [`verification.md`](./verification.md) and to the proposal's Q-d, so it carries weight it has
  not earned from a source. Label it as analysis wherever it is reused.
- **D-LP4 (row 23) — resolved.** `grep -ci comment` over the Bernardy extraction returns **0**
  (row 37). Combined with the APEP grep (row 22) and Yelland's footnote, the claim "among the
  optimality family only Yelland engages with comments" is now verified for all three papers
  held locally. Podkopaev remains unchecked because it is not held.
- **D-LP5 (rows 28, 29) — claims outside this page's evidence base.** Row 27 is now verified
  against a pinned clone. Rows 28–29 still restate findings from the session's `libs/dmd-lsp`
  exploration that are not yet written down anywhere with citations; they become ✓ only when
  [`dmd-lsp-baseline.md`](./dmd-lsp-baseline.md) and its ledger land.
- **D-LP6 (row 17) — small-caps normalization.** The extraction renders the paper's small-caps
  function names with intra-word spaces (`C ONSTRT EXT`, `PUTBACK ` etc.). The doc normalizes
  them. Cosmetic, but noted so the code block is not mistaken for byte-exact.
