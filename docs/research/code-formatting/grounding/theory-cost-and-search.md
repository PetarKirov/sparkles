## Discrepancies & caveats

- **D-CS1 (rows 3, 26, 32) — partly resolved.** scalafmt is described from the 2016 thesis, not
  from source; the repo (`d425e565`) is cloned but unread. The doc now carries a
  `> [!WARNING]` block stating this explicitly and extending the caveat to the dartfmt
  description. The residual risk is unchanged — reading `$REPOS/scala/scalafmt` would upgrade
  rows 3/32 from "as designed in 2016" to current — but it is no longer silent.
- **D-CS2 (row 26) — the dartfmt claim is doubly dated.** Geirsson describes 2016 dartfmt; the
  `dart_style` deep-dive will describe 3.x, which was rewritten. The doc states both, but the
  practice-table cell juxtaposes them in a way that could read as one continuous design.
- **D-CS3 (rows 8, 9) — two load-bearing inferences are ours.** The 80-second figure (row 8) is
  arithmetic the thesis does not perform, and the frontier-never-prunes explanation (row 9) is
  the doc's mechanism, not Geirsson's. Both are sound, both are unsourced. Row 9 in particular
  is the page's central causal claim and should be marked as analysis if challenged.
- **D-CS4 (row 29) — an uncounted count.** "~10 `Penalty*` options" is an estimate written from
  memory of the option list, not from counting `Format.h`. Cheap to fix; do it when
  [`clang-format.md`](./clang-format.md) is written and upgrade the row.
- **D-CS5 (row 33) — resolved by softening.** The doc previously asserted "none cites Yelland or
  Podkopaev", which was never checked. It now claims only that clang-format's search predates
  both papers (true and checkable) and frames the non-communication as an impression rather than
  a finding.
- **D-CS6 (rows 27, 28, 30) — forward references.** Three practice/mechanism rows depend on
  deep-dives not yet written. Re-audit when `dart-style.md`, `d-landscape.md` and
  `clang-format.md` land.
