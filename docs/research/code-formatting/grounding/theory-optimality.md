## Discrepancies & caveats

- **D-Op1 (rows 20, 23) — Podkopaev & Boulytchev is entirely second-hand.** The paper is
  Springer-paywalled and no preprint was located during acquisition. Every claim about it —
  the DP formulation, the tree-vs-DAG limitation, the O(n̂W⁴) bound, the memoization remark —
  comes from `apep23` §2 and Table 1. `apep23` is peer-reviewed and specific, so the claims are
  well-supported, but they are **not verified against the source**. The doc flags this inline
  with a `> [!WARNING]` block; do not upgrade these rows to ✓ without acquiring the paper.
- **D-Op2 (row 6) — a triple-nested attribution.** The doc quotes Bernardy quoting Hughes,
  citing "sec. 7.4 of his paper". Hughes §7.4 has **not** been read (`hughes95` is image-only;
  see [`theory-combinators.md`](./theory-combinators.md) D-C1). Bernardy's rendering is
  presumably accurate, but this survey has not checked it. Same posture as
  [`theory-combinators.md`](./theory-combinators.md) row 39.
- **D-Op3 (row 29) — resolved.** `yelland16`'s footnote reads "draws a distinction between
  between pretty printing" (a duplicated word in the original). The doc now reproduces it with
  `[sic]` rather than silently repairing it, so the quote is faithful.
- **D-Op4 (row 10) — resolved.** The doc now quotes the full sentence, "…that maps a column to
  the minimum cost incurred by the layout when started at that column" (txt L279–281), instead
  of the earlier bracketed abbreviation.
- **D-Op5 (row 25) — the load-bearing Knuth–Plass claim is ours.** "Optimal substructure does
  not hold on line index alone, because indentation depends on earlier choices" is the doc's
  own argument for why the `W` factors appear. It is consistent with every complexity in Table 1
  and with Yelland's column-parameterized DP state, but **no cited source states it**. It is the
  most substantive unsourced assertion on the page and should be labelled as analysis if
  challenged.
- **D-Op6 (row 19) — Table 1 is reproduced, not summarized.** Reproducing a paper's table
  wholesale is unusual for this corpus. It is attributed in the surrounding prose and in the
  `<sub>` footnote. Verify the transcription again if `apep23` is ever replaced by the
  non-appendix PACM version, whose table numbering may differ.
