## Discrepancies & caveats

- **D-O1 (rows 9, 10, 20) — OCR damage.** §4 and §8 body text extracts with intra-word
  spacing. The specific sentences quoted survived intact, but a future editor extending
  those paragraphs must read the PDF directly. Do not copy from the `.txt` for §4/§8.
- **D-O2 (row 33) — the tech report is not local.** The Karlton-appendix provenance rests on
  `pp.rs`'s attestation plus §6's naming of Karlton. Both are strong, and they agree, but the
  appendix itself has not been read. Marked ⚠ 🌐 rather than ✓.
- **D-O3 (row 21) — Hearn & Norman's bounds are conditional in the source.** Oppen writes
  their "analysis assumes that line width is constant, but if line width is assumed to be m,
  their algorithm appears to have the same bounds as Morris' algorithm." The doc's table
  states this as ≈ Morris; the hedge is in the prose but not the table cell.
- **D-O4 (row 31) — the `group`/`fill` correspondence is editorial.** Neither Oppen nor
  prettier's docs assert it. It is this survey's cross-naming, and it is load-bearing for
  [`concepts.md`](./concepts.md)'s IR table, so it is flagged wherever it appears.
