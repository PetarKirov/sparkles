## Discrepancies & caveats

- **D-C1 (rows 1–6) — `hughes95` is image-only evidence.** No text layer. All six Hughes
  quotes were read from 130 dpi renderings of pp. 1 and 3. They are transcribed carefully but
  have not been machine-diffed against a text source, which is a weaker guarantee than every
  other ✓ in this tree. **The Remark (row 6) is load-bearing for the whole survey** — it is
  cited from `combinators.md`, the umbrella, and `dmd-lsp-baseline.md` — so it deserves a
  second reader before the tree merges.
- **D-C2 (row 37) — Wadler cites "Chitil 2001".** The local artifact is the TOPLAS 2005
  publication. Wadler is referring to an earlier version of the same work. The doc presents
  the parenthetical as pointing at the lazy-dequeue line, which is correct in substance, but
  the year in the quote does not match the year in the doc's own citation of `chitil05`.
- **D-C3 (row 39) — Hughes' impossibility claim is second-hand.** The doc attributes "no
  algorithm … optimal and bounded" to Hughes, sourced from Wadler's report of it. The claim
  has **not** been located in `hughes95` itself (which would require reading well past p. 3
  under the image-only constraint). Presented in the doc as "Hughes notes that…", i.e. inside
  the Wadler quote, which is honest — but it is not independently verified.
- **D-C4 (row 23) — one elision in a code excerpt.** Lindig's `(i,Break,DocBreak(_)) :: z -> true`
  clause carries the source comment `(* impossible *)`, dropped in the doc's excerpt. Not
  meaning-changing, but the excerpt is not byte-identical.
- **D-C5 (row 43) — the O(n·w) figure is editorial.** Lindig states no complexity bound for
  his own algorithm beyond avoiding the exponential. The doc's table cell is analysis, and is
  marked as the survey's own in the row above.
- **D-C6 (rows 47, 48) — forward references.** Two practice-table rows point at deep-dives not
  yet written. They are ◯ until those pages and their ledgers land; re-audit then.
